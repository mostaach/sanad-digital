# SANAD Digital

> Digital infrastructure, connected operations, and AI guest concierge systems tailored for Moroccan boutique hospitality, luxury riads, and experiential lodges.

## Overview

SANAD is an end-to-end digital partner for high-touch hospitality operators in Morocco. It connects front-of-house guest touchpoints (WhatsApp direct booking, room QR guides, excursions, spa) directly into core PMS, housekeeping dispatch, and business reporting through a unified digital architecture.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Tech Stack

- **Framework:** Next.js (App Router, Turbopack)
- **Styling:** Tailwind CSS, Radix UI primitives, Lucide Icons
- **Animation & Visuals:** Pure React/SVG CAD architecture diagrams
- **Lead Capture:** Built-in lightweight JSON vault + admin analytics dashboard (`/admin`)

## Deploy on Vercel
